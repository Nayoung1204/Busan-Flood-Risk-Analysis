# Busan Flood Risk Analysis for Busan Big Data Competition in 2026
This project assesses flood risk in Busan, South Korea, by integrating topographic factors (elevation, slope, flow accumulation, and river proximity), land cover, historical flood records, and socioeconomic vulnerability. GIS-based spatial analysis and machine learning are used to identify flood-prone areas.

Note: The code in this repository has been reviewed, revisited, and re-executed step by step to improve my understanding of the analytical workflow and document the methodology. As some preprocessing and analysis steps were reproduced, the results may differ slightly from those originally submitted to the 2026 Busan Big Data Competition.
